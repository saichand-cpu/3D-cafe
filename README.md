# NOIR — 3D Café

A fresh cinematic 3D café website built for a high-impact, Instagram/Reels-friendly visual experience.

## Stack
- Next.js App Router + TypeScript
- React Three Fiber / Three.js / Drei
- Framer Motion
- Responsive CSS

## Run
```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Experience
- Procedural 3D coffee cup and orbiting beans
- Cinematic hero composition
- Scroll-friendly section architecture
- Interactive menu cards
- Story/orb scene
- Editorial gallery
- Reservation CTA
- Mobile responsive layout
- Reduced-motion accessibility support

The contact information is intentionally demo data until the café identity, phone, email and booking system are finalized.
